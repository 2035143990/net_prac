### Q2 奉贤校区和徐汇校区之间是否联网？

- **设计层面联网**：双出口路由器，R1 主用 CERNET，R2 备连梅陇校区并接 Internet；R1 故障切 R2。
- **仿真层面未建该侧节点**：只保留 `internet`（203.0.113.0/24）。
- 追问补充：该链路在真实设备上可用静态路由或 BGP 落地，方案已预留互联网段与 BGP 配置口径。

### Q9 有没有防火墙？

有，双机 fw1/fw2，nftables 落地三区策略。

| 区域 | 连接 | 默认策略 |
| --- | --- | --- |
| Trust | 核心、全部校内 VLAN | 可访问 Untrust、DMZ |
| Untrust | Internet、梅陇校区 | 默认拒绝，仅放行命中 DNAT 的 80/443 |
| DMZ | Web、邮件、对外 DNS、VPN | 外网只可达指定端口，DMZ 不可主动访问内网 |

细节：
- DNAT：`198.51.100.80:80/443 → 10.80.0.10`，只允许 `ct status dnat` 流量；
- SNAT：仅 `iifname eth1 oifname eth2` masquerade，避免改写 DNAT 回程；
- 显式丢弃 Internet 直达 DMZ 私网地址；
- 管理口不对公网开放；
- SEC-01~06、NAT-01~07 全量通过（2026-11-11 回归）。

现场可演示：`docker exec clab-campus-lab-fw1 conntrack -L | grep 203.0.113.100 | head -3`，展示 SNAT 改写源地址。配图 `fig-7-3-firewall-nat.png`。

### Q12 是否考虑了网络的可扩展性、安全性、绿色环保？

**可扩展性**
- 区域汇总路由：核心只看见区域汇总，减少路由表规模；
- 地址规划「地址即含义」：`10.A.B.0/24`，A 表示区域、B 表示楼栋，可平移扩展；
- IPv6 双栈预留；
- 设备按 5–10 年、留 30% 余量选型；
- 新增区域只需增加地址池 + 汇聚 Relay + 汇聚 ACL 地址集合。

**安全性**（新增两项已落地）
- 出口三区防火墙 + NAT + 只开指定端口；
- 宿舍区细粒度 ACL：仅放行宿舍互访、DNS、Internet、DMZ 80/443，其余默认拒绝；
- **生活区隔离**（2026-11-11 新增）：生活区 → 教学/实验/宿舍/图书馆/数据中心/管理网阻断，仅放行 Internet 与 DMZ；
- **数据中心出校限制**（2026-11-11 新增）：数据中心 → Untrust/Internet 阻断，防止敏感数据外流；
- 管理网独立 VLAN 90，业务区不可达；
- 802.1X / Portal + RADIUS 动态 VLAN（设计，仿真未建模）；
- DHCP Snooping、DAI、端口隔离、端口安全、未用端口 shutdown；
- SSH v2、SNMPv3、关闭 Telnet。

**绿色环保**
- 高能效设备型号；
- PoE 按 AP 实际功率（约 15W/台）选型，宿舍百兆口不配 PoE+；
- 机房精密空调 + 冷热通道；
- 统一网管减少现场巡检能耗。
