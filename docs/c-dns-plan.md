## 设计规则

- **内外分设**：内部 DNS 部署在数据中心，负责校内域名权威解析与校内终端递归；外部 DNS 部署在 DMZ，只对外发布域名做权威解析；
- **主备冗余**：内部 2 台、外部 2 台，共 4 台（设计方案 7.5）；
- 校内终端由 DHCP 下发内部 DNS 主节点地址 `10.60.0.10`；
- 外部 DNS 不直接使用公网递归，改为转发到内部 DNS，避免对外暴露内部解析链路；
- 对外只发布 `www` 与 `mail`，均指向 NAT 发布地址 `198.51.100.80`（DNAT 到 DMZ `10.80.0.10`）。
